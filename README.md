# Adnan Kaldybayev — engineering portfolio

Live site: https://adnanadnankaldybayev-design.github.io/portfolio/

Static single-page portfolio (vanilla HTML/CSS/JS, no build step).

Hero feature: the live panel fetches the public daily metrics of
[GridCast](https://github.com/adnanadnankaldybayev-design/gridcast) — my
multi-market electricity demand forecasting system — and renders current
model-vs-baseline results on load, failing gracefully to a stale note.

Design system: Fraunces + Inter, grid-amethyst dark palette (`#090c10` base,
amber-volt accent), mobile-first, WCAG-checked contrast, reduced-motion aware.
